# 流通関係図（Stakeholders）

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    キーコーヒー横持輸送サプライチェーン                    │
└─────────────────────────────────────────────────────────────────────────┘

  ┌──────────────┐         ┌──────────────┐         ┌──────────────┐
  │  飲料工場     │ ◄────── │ 20号物流     │ ──────► │   建会社      │
  │ (Beverage    │  依頼/   │ センター      │  残便   │ (Carrier)    │
  │  Factory)    │  回答    │ (Warehouse)  │  依頼   │              │
  └──────────────┘         └──────┬───────┘         └──────┬───────┘
                                  │                        │
                          自社フリート配車              下請け分割
                                  │                        │
                          ┌───────▼───────┐         ┌──────▼───────┐
                          │ 自社ドライバー  │         │ 下請け業者    │
                          │ 小野・浅川 etc │         │ Subcontractor│
                          └───────────────┘         └──────────────┘
                                  │
                          ┌───────▼───────┐
                          │ ドライバー     │
                          │ (実行・到着確認)│
                          └───────────────┘
```

## システムロール対応

| 実体 | システムロール | ルート |
|------|----------------|--------|
| 20号物流センター | `WAREHOUSE_STAFF` (旧 MARUICHI) | `/warehouse` |
| 飲料工場 | `FACTORY_STAFF` | `/factory` |
| 建会社 | `CARRIER_STAFF` (旧 SHINWA) | `/carrier` |
| 下請け | `SUBCONTRACTOR_STAFF` | `/subcontractor` |
| ドライバー | `DRIVER` | `/driver` |
